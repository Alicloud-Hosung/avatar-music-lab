현재 공개 버전의 동작 방식

음악과 원본 안무 영상은 실제 Model Studio 생성 결과입니다. 몸의 동작은 원본 영상에서 MediaPipe로 추정했습니다. 단안 영상의 깊이 추정과 손 가림에는 한계가 있으며, 입 모양은 Qwen ASR의 단어별 시간에 맞춥니다. 단어 내부의 음절 시간은 보간하므로 음소 단위 강제 정렬과는 차이가 있습니다.

Model Studio와 PAI의 역할

음악과 Wan 영상, ASR은 Model Studio를 사용했습니다. 관절 추출은 현재 로컬 CPU에서 실행합니다. 이를 컨테이너로 묶어 PAI DLC의 비동기 작업으로 옮길 수 있으며, GPU가 필요한 복원 모델로 교체할 경우 그 모델에 맞는 자원을 선택합니다.

오디오가 기준 시계

프레임 수를 더해 시간을 계산하면 재생 중 오차가 쌓일 수 있습니다. 원본 영상과 관절, 아바타, 입 모양과 카메라를 audio.currentTime에 맞춥니다. 영상의 재생 시차가 커지면 같은 시간으로 보정합니다.

캐릭터와 동작의 느슨한 연결

VRM의 정규화된 휴머노이드 인터페이스로 관절을 제어합니다. 캐릭터를 교체할 때는 체형별 발 접지와 관절 가동 범위, 표정 지원 여부를 별도로 검증해야 합니다.

개발자가 살펴볼 구현과 제약

뼈대와 발 접지

정규화된 휴머노이드에 포즈를 적용하고, 두 관절 IK로 무릎과 발 위치를 제어합니다. MediaPipe 관절 좌표를 사용하며 GVHMR이나 SMPL 계열 인체 모델의 결과는 포함하지 않았습니다.

표정과 머리카락

VRM 표정 프리셋으로 눈 깜빡임과 미소를 제어합니다. 입 모양은 Qwen ASR의 단어별 시간에서 보간한 한국어 모음에 맞춰 제어합니다. 머리카락은 VRM의 스프링 본을 사용하며 과도한 움직임을 제한합니다.

공개 페이지의 범위

준비된 음악과 모델로 동작하는 정적 데모입니다. 방문자가 클라우드 API를 호출하는 기능은 없으며 API 키도 포함하지 않습니다.

상용 환경으로 확장

인증과 사용량 제어를 갖춘 서버에서 생성 요청을 처리하고, OSS로 자산을 전달하는 구조로 확장할 수 있습니다. 큐, 검수, 보관 기간과 운영 정책은 서비스에 맞게 설계합니다.
